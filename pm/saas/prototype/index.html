平台營運方 · 我們自己用

平台營運後台

管理客戶、方案、帳務、推薦夥伴、客服與系統
  • 營運儀表板：MRR、租戶數、試用轉換、待處理清單
  • 客戶開發：潛在客戶、試用申請、一鍵建立試用租戶
  • 租戶管理：租戶詳情、健康度、限時授權存取
  • 方案與價格版本、優惠碼、帳單與收款對帳
  • 推薦夥伴與佣金計算、撥付
  • 客服中心、內容管理（範本庫、教學影片）、系統監控、平台設定
租戶 · 物業公司幹部

租戶後台（總公司管理平台） →

示範租戶：永信物業（旗艦版 · 入門級距，8 個服務中社區）
  • 登入：公司代碼＋帳號＋雙因子驗證，服務條款重新同意

  • 員工 LINE 綁定邀請碼、使用率監控與低使用率警示
  • 訂閱與帳單、平台客服授權、資料匯出、終止服務、說明中心

前台 · 社區工作人員個人手機

LINE 前台

不用另裝 App；年長總幹事也用得來的主要入口
  • 綁定流程：加入好友 → 掃邀請碼 → 確認身分 → 選語系
  • 依角色切換的圖文選單（總幹事、保全、清潔、機電）
  • LIFF 頁面：交接日誌、報修、事件通報、巡邏、班表、請假、公告、改善單
  • 推播訊息：緊急事件、逾期工單、每日摘要
前台 · 櫃台共用電腦

網頁前台（櫃台模式／PWA） →

包裹、訪客、管理費收款等櫃台作業；顯示租戶名稱
  • 櫃台模式：點名字＋4 碼 PIN 快速切換使用者
  • 依方案隱藏模組（巡邏、改善單屬專業版；管理費、社區財務屬旗艦版）
  • 提示個人作業改用 LINE
