物業社區管理平台 SaaS 版 · 畫面原型

v0.2 · 三個端：平台營運後台（我們）、租戶後台與前台（物業公司），另含官網申請與租戶開通頁。每個按鈕皆可操作，資料皆為虛構，對應《SaaS 版需求規劃書》v0.6。租戶後台、LINE 前台、網頁前台的資料互相連動，見下方「連動展示」。

連動展示

四個雛型共用同一份資料

平台營運後台、租戶後台、LINE 前台、網頁前台（以及官網試用申請頁）在同一個瀏覽器（Chrome 或 Edge，直接開啟檔案即可）共用資料：在一個頁面操作後，其他已開啟的頁面會即時更新，右下角會出現「↻ 來源・誰・做了什麼」提示。建議把四個頁面開在不同分頁或並排的視窗，一邊操作一邊看另一邊變化。
開啟平台營運後台開啟租戶後台開啟 LINE 前台開啟網頁前台開啟官網試用申請
  1. 報修：LINE 前台切換為保全，拍照送出報修。租戶後台「報修與事件」、網頁前台首頁「今日社區動態」立即出現。
  2. 派工：租戶後台把這張報修指派給機電 王志強。LINE 前台切換為機電，收到推播，在「我的工單」回報完工。
  3. 結案：LINE 前台或網頁前台以總幹事確認結案。後台工單狀態同步變成「結案」。
  4. 事件通報：網頁前台通報一件緊急事件。後台儀表板與通知出現緊急事件，督導收到 LINE 推播。
  5. 請假：LINE 前台以保全申請請假 → 總幹事在 LINE 初審 → 租戶後台「排班請假」核准。申請人在 LINE 收到核准通知，班表同步更新。
  6. 公告：租戶後台發布公司公告。LINE 前台收到推播；員工點開閱讀後，後台的已讀人數即時增加。
  7. 廠商合約：網頁前台（個人登入・總幹事）新增合約草稿並送出 → 租戶後台「廠商與合約 › 前台送出」確認或退回。網頁前台與 LINE 的合約狀態同步更新，退回時顯示原因。
  8. 改善單：租戶後台督導稽核開立改善單 → 總幹事在 LINE 或網頁前台拍照回覆 → 後台複查結案。每一步都會出現在三端的操作紀錄。

平台營運後台連動

  1. 試用申請：官網試用申請頁填寫並送出，點「模擬點擊驗證連結」。平台營運後台「試用申請」立即出現；平台核准後，申請頁即時顯示「已核准・開通信已寄出」。
  2. 改方案：平台營運後台把永信物業的方案改成專業版（不加購帳務模組）。租戶後台的管理費、社區財務立即上鎖；LINE 前台的「支出拍照」改為鎖定，網頁前台的帳務功能隱藏。
  3. 問題回報：租戶後台或 LINE 前台送出問題回報。平台「客服中心」出現新問題；客服回覆後，租戶後台與 LINE 聊天室都收到回覆。
  4. 平台公告：平台營運後台發布公告（後台＋LINE）。租戶後台與網頁前台出現公告橫幅，LINE 聊天室出現「平台公告」卡片。
  5. 客服授權：平台向永信物業申請限時授權 → 租戶後台核准。平台客服進入協助，操作紀錄即時出現在租戶後台的授權紀錄。
  6. 退租與刪除：租戶後台申請退租 → 平台「退租與資料刪除」出現倒數 → 平台執行刪除。租戶後台顯示刪除證明；LINE 與網頁前台顯示「服務已終止」，寫入動作改為說明。
  7. 功能開關：平台把「交接日誌語音輸入」關閉或只開給特定租戶。LINE 前台的語音輸入按鈕即時隱藏或出現。
  8. 帳單與狀態：平台把永信物業設為「唯讀」或登記收款恢復正式。三個租戶端頁面即時出現或移除唯讀橫幅。
每個頁面右下角都有「資料連動中」標示與「重置示範資料」按鈕，按下後三個雛型都會回到初始狀態。
注意：Firefox 直接開啟檔案時，每個檔案的資料是獨立的，無法連動；展示請使用 Chrome 或 Edge。開通頁（activate.html）是固定示範，不在連動範圍內。

前台 · 社區工作人員個人手機

LINE 前台

不用另裝 App；年長總幹事也用得來的主要入口
  • 綁定流程：加入好友 → 掃邀請碼 → 確認身分 → 選語系
  • 依角色切換的圖文選單（總幹事、保全、清潔、機電）
  • 上下班打卡（GPS 範圍或掃 QR、範圍外打卡、補卡申請）
  • LIFF 頁面：交接日誌、報修、事件通報、巡邏、班表、請假、公告、改善單
  • 邀請碼 8 碼、錯誤 5 次鎖定；工作階段逾期重新驗證；離職停用
  • 照片自動壓縮並移除位置資訊；巡邏 PWA 離線備案；共用或自有官方帳號

官網表單送出後進入平台營運後台的潛在客戶清單
